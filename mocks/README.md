# Mocks

Datos de ejemplo para probar la app sin empezar de cero.

## `pachi-ejemplo.json`

Copia de exportación con 12 contadores (10 automáticos y 2 manuales) que cubren
todos los tipos: `quit`/`build`, todos los colores e iconos variados, hitos por
defecto y personalizados, rangos desde 1 día hasta 365, además de una colección
de 5 discos prensados y ajustes (tono, recordatorio, sonido).

### Cómo cargarlo

Ajustes › Datos › **Importar JSON** → **Elegir archivo** (o pega el contenido)
→ **Cargar datos**.

Nota: importar **reemplaza** los datos actuales. Exporta antes si quieres
conservar lo que tengas.
